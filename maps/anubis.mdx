Anubis features a comprehensive set of CT smoke line-ups with 8 different positions, plus limited T side utility options.

## CT Side Line-ups

The CT side configuration provides 8 smoke positions distributed across the radio wheels.

### Primary Wheel (Tab 0)
- **Position 1**: Smoke 6
- **Position 2**: Smoke 7
- **Position 3**: Smoke 8
- **Position 8**: Smoke 5

### Secondary Wheel (Tab 1)
- **Position 1**: Smoke 2
- **Position 2**: Smoke 3
- **Position 3**: Smoke 4
- **Position 8**: Smoke 1

### Tertiary Wheel (Tab 2)
- **Position 1**: Smoke 6
- **Position 2**: Smoke 7
- **Position 3**: Smoke 8
- **Position 8**: Smoke 5

<Info>
  The tertiary wheel on Anubis CT side mirrors the primary wheel, providing quick access to the same essential smokes.
</Info>

## T Side Line-ups

The T side configuration is minimal, with limited utility options.

### Primary Wheel (Tab 0)
- **Position 1**: More options (not supported)
- **Position 3**: Scroll for more utilities
- **Position 7**: Scroll for more utilities

### Secondary Wheel (Tab 1)
- **Position 1**: Molly 1

### Tertiary Wheel (Tab 2)
- Scroll navigation for extended utilities

<Tip>
  Anubis is CT-sided in the CSAFAP configuration with extensive defensive options. T side relies more on default utility usage.
</Tip>

## Configuration Files

Source files: `~/workspace/source/csafap/maps/anubis/`
- `anubis_CT_labels.cfg` - CT side radio wheel labels
- `anubis_T_labels.cfg` - T side radio wheel labels
- `anubis_CT_cmd.cfg` - CT side command bindings
- `anubis_T_cmd.cfg` - T side command bindings
