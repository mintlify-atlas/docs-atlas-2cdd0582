Ancient features comprehensive smoke line-ups for both CT and T sides, with particular focus on B site control and A site executes.

## CT Side Line-ups

The CT side configuration provides defensive smokes for both bombsites.

### Primary Wheel (Tab 0)
- **Position 1**: B Site Smoke 3
- **Position 2**: B Site Smoke 4
- **Position 3**: B Site Smoke 5
- **Position 7**: B Site Smoke 1
- **Position 8**: B Site Smoke 2

### Secondary Wheel (Tab 1)
- **Position 2**: A Site Smoke 4
- **Position 3**: A Site Smoke 5

### Tertiary Wheel (Tab 2)
- **Position 1**: CT Smoke 3
- **Position 2**: CT Smoke 4
- **Position 3**: CT Smoke 5
- **Position 7**: CT Smoke 1
- **Position 8**: CT Smoke 2

<Info>
  Ancient CT side focuses heavily on B site defense with 5 different smoke positions available on the primary wheel.
</Info>

## T Side Line-ups

The T side configuration includes essential smokes and mollies for site executes.

### Primary Wheel (Tab 0)
- **Position 1**: More options (not supported)
- **Position 3**: Scroll for more utilities
- **Position 7**: Scroll for more utilities

### Secondary Wheel (Tab 1)
- **Position 2**: B Site Molly
- **Position 4**: Smoke 5
- **Position 5**: Smoke 4
- **Position 6**: Smoke 1
- **Position 7**: Donut Smoke

### Tertiary Wheel (Tab 2)
- Scroll navigation for extended utilities

<Tip>
  The "Donut Smoke" is a signature Ancient utility that blocks vision through the middle area between sites.
</Tip>

## Configuration Files

Source files: `~/workspace/source/csafap/maps/ancient/`
- `ancient_CT_labels.cfg` - CT side radio wheel labels
- `ancient_T_labels.cfg` - T side radio wheel labels
- `ancient_CT_cmd.cfg` - CT side command bindings
- `ancient_T_cmd.cfg` - T side command bindings
