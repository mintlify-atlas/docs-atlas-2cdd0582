## How Map Configurations Work

<Info>
  Map-specific configurations are automatically loaded when you join a server running that map. The radio wheel bindings give you instant access to utility line-ups.
</Info>

Each map includes:
- **CT Side Line-ups**: Defensive smokes, mollies, and wallbangs
- **T Side Line-ups**: Offensive smokes and utility for site executes
- **Radio Wheel Integration**: Three radio wheels (primary, secondary, tertiary) with custom labels

## Radio Wheel Navigation

The CSAFAP package uses CS2's radio wheel system with three tabs:
- **Tab 0 (Primary)**: Main utility line-ups
- **Tab 1 (Secondary)**: Additional utility options
- **Tab 2 (Tertiary)**: Extended configurations

<Tip>
  Use the scroll indicators in the radio wheel to navigate between different utility sets on each map.
</Tip>
