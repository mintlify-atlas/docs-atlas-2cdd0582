# CS as fast as possible - Config Package

This .cfg-framework enables CS2 players to utilize advanced features and customization, which are all **legal to use on official Valve's matchmaking or Premier servers, as well as on FaceIt servers**.

## Why CSAFAP?

CSAFAP brings advanced CS2 customization through a legal, config-based framework. Access powerful features through intuitive radio wheels, completely legal for competitive play.

## Is This Legal?

<Info>
**Yes!** CSAFAP is legal on all major platforms:
- **Matchmaking & Premier**: Works purely on in-game commands that function under sv_cheats 0
- **FaceIt**: Fully allowed for ranked PUGs (not allowed in higher leagues like ESEA, ESL)
- Uses only legal commands and modified language text files
</Info>

<Warning>
While allowed on FaceIt for regular ranked games, CSAFAP configs are **not allowed** in higher leagues like ESEA or ESL, as their rules prohibit the use of the alias command in general.
</Warning>

## How It Works

The CSAFAP Config Package uses CS2's built-in radio wheel system to provide quick access to advanced features. By pressing one of the four keybinds (default: H, J, K, M), you open a customized radio wheel with various options.

**Default Keybinds:**
- **H**: CT Line-ups (Smokes & Wallbangs)
- **J**: T Line-ups (Smokes & Wallbangs)  
- **K**: Pro crosshairs, Rapid fire pistols, Better Follow-Recoil, and Snap-Tap/Null binds
- **M**: Map Selection + Practice Mode
